# Breast Cancer Prediction Project

This project predicts whether a breast tumor is **benign** or **malignant** using the Breast Cancer Wisconsin dataset.  
The goal is to understand the data through Exploratory Data Analysis (EDA) and build a simple and effective machine learning model.

---

## Overview

Breast cancer detection is important for early diagnosis.  
In this project, I explored medical feature data, visualized key patterns, cleaned and standardized the dataset, and built a Logistic Regression model for prediction.

---

## What’s Included

- Data loading and preprocessing  
- Exploratory Data Analysis (EDA)  
- Visualizations to understand feature behavior  
- Standardizing the dataset  
- Logistic Regression model training  
- Accuracy and classification report  
- Final evaluation results  

---

## About the Dataset

The dataset used is available in `scikit-learn` and contains:

- **569 records**
- **30 numeric features**
- Target labels:  
  - `0` → Malignant  
  - `1` → Benign  

Example features include:
- Mean radius  
- Mean texture  
- Mean smoothness  
- Mean perimeter  

---

## Steps Followed

1. Load and explore the dataset  
2. Perform EDA to understand feature patterns  
3. Scale features for better model performance  
4. Train Logistic Regression  
5. Evaluate the model using accuracy and confusion matrix  

---

## Model Performance

The Logistic Regression model achieved an accuracy of around **96%**.  
The confusion matrix shows good separation between benign and malignant classes.
